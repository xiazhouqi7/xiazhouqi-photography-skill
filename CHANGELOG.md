# Changelog

All notable changes to `xiazhouqi-photography-skill` are recorded here.

## 1.0.0 — 2026-08-16

### Added

- Initial flexible photography skill framework
- General rules for composition, color grading, retouching, depth and atmosphere
- Modular `styles/` structure for future visual directions
- First style: `Italian Slow Travel｜意大利慢旅行摄影`
- Chinese and English README files

### Philosophy

The repository starts as a broad photography system rather than a single locked preset. Future styles can be added, reorganized or refined without creating a separate repository.
