# Xiazhouqi Photography Skill｜下周七摄影风格库

这是一个用于**摄影、调色、修图与视觉风格管理**的长期仓库。

属于 **[Xiazhouqi](https://xiazhouqi7.com)** 创作体系。

它不会被固定成某一种滤镜或某一位摄影师的单一风格，而是作为一套可以持续扩展的摄影系统：以后遇到新的街拍、旅行、风景、夜景、胶片或电影感风格，都可以继续加入这个仓库，不需要重新创建 Repository（仓库）。

## 主要范围

- 摄影构图与二次裁切
- 调色与色彩关系
- 光影与氛围塑造
- 修图、杂物整理与画面净化
- 前景 / 中景 / 远景层次
- 景深、运动模糊与空气感
- 胶片质感与电影感
- 街景、旅行、风景及日常摄影
- 根据原图自动判断适合的处理方向

文件夹结构并不是永久固定的。随着风格增加，可以继续新增、拆分、重命名或重新分类。

## 当前第一套风格

### Italian Slow Travel｜意大利慢旅行摄影

核心视觉语言：

- 先处理构图，再处理颜色
- 近景可以适度失焦或带运动模糊
- 中远景主体保持清晰
- 暖色电影感，但不过度偏黄
- 夜景保留夜晚本身的暗部
- 霓虹不过饱和，不做廉价赛博朋克
- 保留旧楼、招牌、车辆、线缆和生活痕迹
- 轻微胶片感，避免重 HDR 和过度锐化
- 最终更像一段旅行记忆，而不是商业广告大片

详见 [`styles/italian-slow-travel.md`](styles/italian-slow-travel.md)。

## 长期原则

> 不先套滤镜，先读懂照片。

每一张图都应该先判断：主体是谁、哪些内容值得留下、哪里需要模糊、哪里需要清晰、什么颜色属于现场本身。

这个仓库会随着审美、拍摄经验和新的摄影参考不断更新。
